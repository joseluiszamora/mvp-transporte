# Base compartida — paquete de instrucciones para Codex
Fecha: 2026-10-14. Estado: especificación inicial acordada; implementación pendiente.
Repositorio destino: https://github.com/joseluiszamora/mvp-transporte

## Uso
1. Copiar AGENTS.md y docs/ a la raíz del repositorio. No sobrescribir un README o instrucciones existentes sin revisar su contenido.
2. Leer docs/product.md, architecture.md y decisions.md.
3. Usar docs/codex-start.md como primer mensaje a Codex.
4. Crear las issues a partir de docs/tasks/ y usar docs/tracking.md para el seguimiento.
5. Ejecutar las tareas en orden de dependencias. La documentación no implica que exista código ni que las issues hayan sido creadas.

Este paquete no modifica GitHub y no contiene credenciales. Las versiones de dependencias se fijarán al implementar fundamentos, verificando compatibilidad en documentación oficial.
