# Documentos de módulos

## Convención

- ADM-XX refiere a un módulo compartido de mvp-base. Este repositorio mantiene solo una ficha de referencia y sus contratos de integración.
- TRN-XX identifica módulos propios de mvp-transporte.
- Cada ficha describe alcance, reglas, entidades, permisos, estados y criterios de aceptación del dominio.
- Una implementación debe actualizar la ficha cuando una regla aprobada cambie.
