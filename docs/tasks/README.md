# Tareas de implementación

## Uso

Cada archivo TASK-XXX describe una entrega concreta que puede convertirse en una Issue o Milestone de GitHub. Mantener una tarea acotada, revisable y con criterios de aceptación observables.

TASK-007 registra una dependencia cuyo código se implementa en mvp-base. La referencia de mvp-base no se modifica desde este repositorio hasta contar con alcance explícito en ese proyecto.

## Contenido obligatorio

- Objetivo.
- Prerrequisitos y dependencias.
- Alcance incluido y excluido.
- Pasos sugeridos.
- Criterios de aceptación.
- Documentos que deben actualizarse.
- Estado: Pendiente, En curso, Bloqueado, En revisión o Completado.

Una tarea se completa mediante un Pull Request vinculado. El estado del roadmap se actualiza al integrar el cambio.
